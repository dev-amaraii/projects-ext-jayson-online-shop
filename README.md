# Jayson Tech Online Shop

Customer-facing ecommerce storefront for NEN International's phone-accessories retail customer.

## Design direction

- Approved responsive Gadget Marketplace template (desktop and mobile).
- Samsung is a demonstration brand only, pending the retailer's final choice.
- Frontend: Turborepo, TanStack Start, React, shadcn/ui, Tailwind, TanStack Query, Zustand.
- Planned backend: NestJS, PostgreSQL, Drizzle, Redis, BullMQ.
- Planned payments: NEN Payment / Paystack.
- Planned shared commerce catalogue and inventory with AmaraiiOS POS.

## Status

UI/UX demo in progress. Product data, prices, delivery terms and payment methods are placeholders until confirmed.
